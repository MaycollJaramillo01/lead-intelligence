# Security and threat model

Lead Intelligence runs on one Windows machine for one analyst. It reads untrusted web content,
imported files and local model answers, and stores business contact data. It has no server, no
account, no telemetry and no outbound channel other than the fetches the analyst starts.

## 1. Assets and trust boundaries

```text
analyst ─ webview (React, CSP) ─ IPC: invoke/listen only ─ desktop core (Rust)
                                                           ├─ save dialog, one-time grants
                                                           └─ worker (Python sidecar, stdin/stdout JSON Lines)
                                                                ├─ SQLite · DuckDB · Parquet · artifacts (data dir)
                                                                ├─ the web (discovery, crawler): untrusted
                                                                ├─ Chromium (Playwright, Edge or Chrome): untrusted pages
                                                                ├─ Ollama on loopback: untrusted answers
                                                                └─ files the analyst imports: untrusted
```

| Asset                           | Why it matters                                     |
| ------------------------------- | -------------------------------------------------- |
| Stores under the data directory | Business contacts, evidence, research decisions    |
| Exports and their manifests     | Leave the app; may reach other people              |
| Logs                            | Job detail, request ids, business ids              |
| The machine itself              | A crawler or a model must never run commands on it |

## 2. Threats, mitigations and evidence

| Threat                                     | Mitigation in place                                                                                                                                                                                                                                                        | Evidence                                                                                                                                                                                                                     |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Untrusted web content, stored HTML         | Bodies are stored as artifacts and parsed with selectolax; the interface never renders fetched HTML (no `dangerouslySetInnerHTML`, no iframe); CSP `default-src 'self'`, images only `self` and `data:`                                                                    | `grep` of `apps/desktop/src` (no match); `tauri.conf.json`                                                                                                                                                                   |
| Prompt injection from pages                | Models only fill strict schemas; answers cite given inputs or are rejected; a model's answer is shown as such, never as a fact and never changes a deterministic score; no tool, network or command capability is given to a model                                         | `test_ai_tasks.py`, `test_ai_live.py[injection_*]`, D-064…D-069                                                                                                                                                              |
| SSRF, DNS rebinding, redirects             | `crawl.guard`: public addresses only, checked after DNS resolution and on every redirect hop; no proxy from the environment; loopback, private, link-local and metadata ranges refused; redirect chains bounded and audited                                                | `test_the_guard_refuses_private_targets_before_any_request`, `test_a_name_resolving_to_a_private_address_is_refused`, `test_redirect_loops_chains_and_escapes_are_audited`, IPC `the_crawl_flow_runs_end_to_end_through_ipc` |
| Path traversal                             | Stored paths are relative and resolved with `storage.data_path`, which refuses anything outside the data directory; imports read only artifacts inside it; export destinations must be absolute, local, existing, with the format's extension and outside the app's stores | `test_a_stored_path_never_leaves_the_data_directory`, `test_a_destination_is_a_local_file_outside_the_app_stores`                                                                                                            |
| Zip slip                                   | Nothing extracts archives. XLSX is written (never read) with fixed member names                                                                                                                                                                                            | `exports.write_xlsx`                                                                                                                                                                                                         |
| Command injection                          | Two subprocesses, both with an absolute path from `shutil.which`, fixed argument lists, no shell (`nvidia-smi`, `llmfit`); the core starts the worker with `Command` arguments, no shell, no window                                                                        | `gpu.py`, `ai/llmfit.py`, `worker.rs`                                                                                                                                                                                        |
| SQL injection                              | Every value is a bound parameter; dynamic SQL only joins fixed column names from the model (`# noqa: S608` marks each one)                                                                                                                                                 | ruff `S608` reviewed per site; explorer filter compiler tests                                                                                                                                                                |
| Tauri permissions and IPC surface          | The window may only `invoke` the app's own commands and `listen`/`unlisten` to events (capability `default`); every command validates its payload in Rust before it reaches the worker; the page never names a file path                                                   | `capabilities/default.json`, `data.rs`, `tests/contracts.rs`, `tests/ipc.rs`                                                                                                                                                 |
| Localhost APIs and ports                   | The app opens no port. The core and the worker talk over pipes. Ollama must be on loopback (configuration refuses other hosts)                                                                                                                                             | `config.rs` tests                                                                                                                                                                                                            |
| Secrets and API keys                       | None are needed or stored: sources that need credentials are disabled by rule; configuration files must not hold secrets; `.env*` and `config/local.toml` are ignored by git                                                                                               | `discovery/registry.py`, `.gitignore`, secret scan in the phase 14 report                                                                                                                                                    |
| Personal business data in logs and exports | Logs are local JSON files with daily rotation (14 files); events hold ids and codes, not page bodies; exports leave out do-not-contact leads by default and never include guessed addresses; every export records who and where                                            | `logging.rs`, D-086, `test_exports.py`                                                                                                                                                                                       |
| CSV/XLSX formula injection                 | Leading `= + - @`, tab and CR get an apostrophe; XML-invalid characters dropped; cell and row limits                                                                                                                                                                       | `test_spreadsheets_make_formulas_inert_and_every_format_keeps_unicode`                                                                                                                                                       |
| Malicious imported files                   | Size, column (200) and value (2 000 characters) limits; values are stored as text, never evaluated                                                                                                                                                                         | `discovery/sources/file_import.py`, `test_discovery.py`                                                                                                                                                                      |
| Local models and their answers             | Loopback runtime only, per-task schema, timeouts, cancellation, circuit breaker, raw answer stored next to what validated                                                                                                                                                  | `docs/local-ai.md`                                                                                                                                                                                                           |
| Dependencies and supply chain              | Lockfiles for every ecosystem (`pnpm-lock.yaml`, `Cargo.lock`, `uv.lock`) installed frozen; SBOM and vulnerability scan per release                                                                                                                                        | `scripts/sbom.py`, phase 14 report                                                                                                                                                                                           |
| Destructive operations                     | Retention, event cleanup, merges and bulk actions are previewed first and applied with a reason; stores are quarantined, never deleted; backups before migrations                                                                                                          | D-078, D-085, `storage.py`                                                                                                                                                                                                   |
| Two app instances on one store             | Second launch focuses the running window instead of opening the stores again                                                                                                                                                                                               | `tauri-plugin-single-instance` in `lib.rs`                                                                                                                                                                                   |

## 3. Known gaps

| Gap                                                                 | Impact                                                  | Next step                                                           |
| ------------------------------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------- |
| Builds are not code-signed (no certificate exists)                  | SmartScreen warns on install; tampering is not detected | Sign with a real certificate ([packaging.md](packaging.md#signing)) |
| Data at rest is not encrypted                                       | Anyone with the Windows account reads the stores        | Rely on BitLocker; document it for the user                         |
| The app's own commands are not listed one by one in an app manifest | A script injected into the page could call any command  | CSP and no rendered HTML keep that unlikely; add an app manifest    |
| No support bundle with redaction                                    | Diagnostics are shared by copying log files by hand     | Add a redacted bundle command                                       |
